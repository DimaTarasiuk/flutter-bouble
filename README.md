# Login App (Neumorphic UI)

Простий Flutter-проект з екраном входу у неоморфному (soft UI) стилі, як на скріншоті.

## Як запустити на Pixel 8

1. Встанови Flutter SDK (якщо ще нема): https://docs.flutter.dev/get-started/install
2. Розпакуй/скопіюй цю папку `login_app` до себе.
3. У терміналі в папці проєкту:
   ```
   flutter pub get
   flutter run
   ```
   Якщо Pixel 8 підключений по USB з увімкненою відладкою USB — додаток запуститься прямо на телефоні.

## Як зібрати APK для встановлення вручну (локально, потрібен Flutter SDK)

```
flutter build apk --release
```

Готовий файл буде тут: `build/app/outputs/flutter-apk/app-release.apk`
Перекинь його на телефон (через USB, Google Drive, Telegram і т.д.) і встанови (потрібно дозволити встановлення з невідомих джерел).

## Як зібрати APK через GitHub Actions (без Android Studio, без Flutter SDK на своєму комп'ютері)

У проєкті вже є файл `.github/workflows/build-apk.yml` — це рецепт для безкоштовного CI від GitHub, який сам поставить Flutter, згенерує відсутню папку `android/` (в архіві її нема — вона згенерується автоматично прямо на CI) і збере APK. Тобі нічого локально ставити не треба.

1. Створи новий репозиторій на GitHub (наприклад `login-app`)
2. Залий туди вміст цієї папки (`git init`, `git add .`, `git commit`, `git push`) — або просто перетягни файли через веб-інтерфейс GitHub
3. Перейди у вкладку **Actions** репозиторію — workflow запуститься автоматично при пуші (або натисни "Run workflow" вручну)
4. Через 2-4 хвилини збірка завершиться, зайди у відповідний запуск і в розділі **Artifacts** внизу сторінки буде `app-release` — качай, там APK
5. Перекинь APK на Pixel 8 і встанови

Якщо не хочеш локально запускати `flutter create .` — скажи, я одразу перепишу workflow так, щоб він сам створював android/ip-структуру прямо на CI перед збіркою.

## Що всередині

- `lib/main.dart` — весь UI екрана входу (одним файлом для простоти):
  - неоморфні "випуклі" картки (аватар, кнопка "Увійти")
  - неоморфні "вдавлені" поля вводу (Логін, Пароль)
  - перемикач видимості пароля (іконка ока)
  - валідація на порожні поля + заглушка замість реального запиту на сервер (TODO в коді, де його підключити)

Дизайн суто фронтендовий — авторизація ще не підключена до жодного бекенду.
